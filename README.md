# Belgian Roads

Jeu d'arcade sur les autoroutes belges : traverse la Belgique jusqu'à la frontière en évitant les nids-de-poule, les travaux, les bouchons et les radars, et laisse passer les ambulances.

**Jouer :** https://mikaboux.github.io/belgian-roads/

## Commandes
- Glisser ← → (ou toucher un côté) : changer de bande
- Glisser ↑ ↓ : vitesse 1, 2 ou 3
- Barre de compétences : cornets de frites (3 = tempête qui balaie l'écran) et Roadstar (propulseurs)
- Clavier : ← → ↑ ↓, Espace = Roadstar, F = cornets, P = pause

Prototype : les pubs et l'achat « sans pub » sont simulés.
